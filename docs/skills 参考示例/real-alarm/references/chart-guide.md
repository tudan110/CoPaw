# 图表展示指南

本文档描述告警数据的图表展示方式和选择原则。

## 图表类型选择

| 分析维度 | 推荐图表 | 说明 |
|---------|---------|------|
| 告警级别 | 环形图（donut） | 展示严重程度占比，中心空白更显专业 |
| 告警状态 | 环形图（donut） | 活跃/已清除对比 |
| 告警标题 | 柱状图（bar） | Top展示，便于数量对比 |
| 设备告警 | 柱状图（bar） | Top设备对比 |
| 专业分布 | 饼图（pie） | 分类占比 |
| 区域分布 | 饼图（pie） | 区域占比 |
| 时间趋势 | 折线图（line） | 变化趋势 |

## 按数据量选择

| 数据量 | 推荐图表 |
|--------|---------|
| 2-5 项 | 环形图 |
| 5-15 项 | 饼图或柱状图 |
| 15+ 项 | 柱状图（避免饼图过于拥挤） |
| 时间序列 | 折线图 |

## 按展示目的选择

| 展示目的 | 推荐图表 |
|---------|---------|
| 占比分析 | 环形图 / 饼图 |
| 对比分析 | 柱状图 |
| 趋势分析 | 折线图 |
| Top 展示 | 柱状图（降序排列） |

## 配置最佳实践

### 饼图 / 环形图

- 半径：饼图 `56%`，环形图 `["40%", "68%"]`
- 标签：右侧居中（`legend: right: "5%", orient: "vertical"`）
- Tooltip：`{b}: {c}条 ({d}%)`

### 柱状图

- X轴标签：旋转 30 度（避免重叠）
- Y轴：标注单位 `数量（条）`
- 柱宽：最大 40
- Grid：`left 48, right 24, bottom 72, top 56`

### 颜色方案

```javascript
const severityColors = {
  1: "#ff4d4f",  // 紧急 - 红色
  2: "#fa8c16",  // 严重 - 橙色
  3: "#1890ff",  // 普通 - 蓝色
  4: "#52c41a"   // 预警 - 绿色
};
```

## 综合分析图表组合

1. 概览：告警级别分布（环形图）
2. 详细：告警标题 Top（柱状图）+ 设备告警 Top（柱状图）
3. 分类：专业分布（饼图）+ 区域分布（饼图）

## 注意事项

- 优先使用 ECharts，备选 Mermaid
- 不要生成 PNG 等图片文件；图表必须可直接在页面渲染
- 大数据量时使用抽样，避免过多动画
- 不要使用实验性 ECharts API
