# 应用层故障根因分析（4场景）

## 1. 代码缺陷

**故障现象**：应用服务异常退出、内存持续增长、响应延迟逐渐升高，业务处理异常或服务不可用。

**根因类型**：
- 内存泄漏（对象未释放、缓存未清理、资源未关闭）
- 线程死锁（多线程竞争、锁顺序不一致）
- 空指针异常（未判空、并发访问共享对象）
- 资源未释放（连接未关闭、文件句柄未关闭）
- 并发竞争（数据竞争、计数器错误）

**分析步骤**：
1. **告警识别**：接收应用层异常告警（服务不可用、错误率升高、响应延迟超过阈值），或应用日志中的异常堆栈信息（NullPointerException、OutOfMemoryError等）。
2. **拓扑关联**：通过应用拓扑确认异常服务的上下游依赖关系；检查是否为单个服务问题还是多个服务同时受影响。
3. **性能指标分析**：查看应用的CPU使用率、内存使用率、GC频率和耗时、线程池状态、请求队列长度等性能指标。
4. **根因判定**：
   - 内存使用率持续增长且GC无法回收 → 内存泄漏
   - 线程池活跃数达到上限且请求排队 → 线程死锁
   - 日志中频繁出现NullPointerException → 空指针异常
   - 连接数持续增长且不释放 → 资源未释放
   - 计数器值异常且并发访问时出现 → 并发竞争
5. **影响评估**：结合应用拓扑和业务指标，评估代码缺陷影响的业务范围和程度。

## 2. 业务逻辑异常

**故障现象**：业务处理结果与预期不符、数据不一致、事务回滚异常，但服务本身可能正常响应。

**根因类型**：
- 状态机错误（业务状态转换逻辑异常）
- 数据一致性破坏（分布式事务失败、最终一致性问题）
- 幂等性失效（重复请求导致数据重复处理）
- 事务回滚失败（补偿事务未正确执行、回滚不完整）

**分析步骤**：
1. **告警识别**：接收业务监控告警（业务处理失败率升高、数据一致性检查失败、事务回滚异常等），或应用日志中的业务异常信息。
2. **拓扑关联**：通过应用拓扑确认异常业务涉及的服务链路；检查是否有多个服务同时报告数据不一致。
3. **性能指标分析**：查看业务处理成功率、事务失败率、数据一致性检查结果等指标。
4. **根因判定**：
   - 业务状态转换与预期不符且日志显示状态机异常 → 状态机错误
   - 分布式事务失败且数据不一致 → 数据一致性破坏
   - 重复请求导致数据重复处理 → 幂等性失效
   - 补偿事务未正确执行 → 事务回滚失败
5. **影响评估**：结合应用拓扑和业务指标，评估业务逻辑异常影响的业务范围和程度。

## 3. 依赖服务故障

**故障现象**：下游服务超时或不可用，本服务调用链路受影响，业务功能降级或中断。

**根因类型**：
- 下游超时（下游服务响应变慢导致调用链路超时）
- 第三方API异常（第三方服务不可用、接口变更）
- 服务降级（依赖服务部分功能不可用，触发降级策略）
- 熔断触发（下游服务错误率超过熔断阈值）

**分析步骤**：
1. **告警识别**：接收应用层服务调用失败告警、熔断器触发告警、或下游服务不可用告警。
2. **拓扑关联**：通过应用拓扑确认异常服务的下游依赖链路；检查是否有多个上游服务同时受到同一下游服务影响。
3. **性能指标分析**：查看服务调用链路的响应延迟、错误率、调用成功率等指标；检查下游服务的健康状态和性能指标。
4. **根因判定**：
   - 下游服务响应延迟升高且本服务超时 → 下游超时
   - 第三方服务不可用且无其他内部告警 → 第三方API异常
   - 下游部分功能不可用且触发降级策略 → 服务降级
   - 熔断器触发且下游错误率超过阈值 → 熔断触发
5. **影响评估**：结合应用拓扑和业务指标，评估依赖服务故障影响的业务范围和程度。

## 4. API与接口故障

**故障现象**：API调用失败率升高、接口超时、参数校验失败、限流拒绝，业务功能异常。

**根因类型**：
- 接口超时（处理时间过长、超时配置不当）
- 参数校验缺失（输入参数未校验导致处理异常）
- 限流拒绝（请求量超过限流配置）
- 序列化异常（数据格式不匹配、版本不兼容）

**分析步骤**：
1. **告警识别**：接收API网关的限流告警、接口错误率阈值告警、或应用日志中的参数校验失败、序列化异常等信息。
2. **拓扑关联**：通过应用拓扑确认异常API的调用方和被调用方；检查是否有多个调用方同时受影响。
3. **性能指标分析**：查看API的响应延迟、错误率、请求量、限流拒绝数等指标。
4. **根因判定**：
   - 接口响应延迟持续升高且超时拒绝增多 → 接口超时
   - 日志显示参数校验失败且错误码为400类 → 参数校验缺失
   - 限流拒绝告警触发且请求量超过限制 → 限流拒绝
   - 序列化异常且数据格式不匹配 → 序列化异常
5. **影响评估**：结合应用拓扑和业务指标，评估API故障影响的业务范围和程度。
