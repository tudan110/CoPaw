# 机房动环层故障根因分析（6场景）

> **使用场景**：当告警来自机房动环监控（温湿度、漏水、烟感、UPS、配电、精密空调、发电机、门禁、视频、动环采集器/网关）时，参考本文档。机房动环是 IT 系统的物理底座，其故障常沿"动环→IT 设备→网络→业务"链路向上传播，是级联故障的高频源头。分析依赖动环传感器数据 + 机房-机柜-设备拓扑定位受影响 IT 资源。

---

## 1. 供配电系统故障

**故障现象**：机房供电中断或异常，UPS/配电告警，部分或全部机柜设备掉电，业务大面积中断。

**根因类型**：
- 市电中断（电力公司停电、外部线路故障、输入电压为0）
- UPS过载（负载率超额定值、切旁路、蜂鸣报警）
- UPS电池老化（后备时间缩短、内阻升高、单体电压异常）
- 配电开关跳闸/支路掉电（过载或短路触发、开关OFF）
- 发电机启动失败（油位不足、电池亏电、启动马达故障，市电中断后无后备）

**分析步骤**：
1. **告警识别**：接收市电输入电压、UPS状态、电池电压、配电开关状态、发电机启动告警。
2. **变更关联**：核查近期是否有新增上架设备、配电改造、UPS/电池维护割接。
3. **拓扑关联**：基于机房-配电-机柜拓扑，定位受影响机柜及其承载的IT设备与业务。
4. **性能指标分析**：查看市电输入电压、UPS负载率/输入输出电压、电池组单体电压与内阻、各支路电流、发电机油位/启动状态的时序。
5. **根因判定**：
   - 市电输入电压为0 + UPS转电池 → 市电中断
   - UPS负载率超额定 + 切旁路 → UPS过载
   - 电池后备时间骤降/单体电压异常 → 电池老化
   - 单机柜掉电 + 对应支路开关OFF → 配电开关跳闸（需排查过载/短路）
   - 市电中断后发电机未启动 + 启动报警 → 发电机启动失败
6. **影响评估**：评估受影响机柜及承载业务，结合UPS剩余后备时间评估业务可坚持时长与紧急度。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：确认后备能力：市电中断且 UPS 后备不足 → 立即启动发电机/切备用市电，非核心负载有序降载；UPS 过载 → 切旁路并卸载非关键负载；支路跳闸 → 确认无短路后试送电。
- 🔧 **根因处置（修复）**：修复市电线路、更换老化 UPS 电池、检修配电开关、排查发电机启动链路（油位/电池/启动马达）。
- 🧭 **影响范围决策**：承载核心机房且无有效后备 → 先保供电（发电机/备路）再修根因；具备充足 UPS/双路冗余 → 可在监控下直接检修故障单元。

## 2. 制冷系统故障

**故障现象**：机房温度持续上升、出现局部热点，精密空调告警/离线，可能导致IT设备过热降频或宕机。

**根因类型**：
- 精密空调故障停机（压缩机/风机故障、面板报警离线）
- 制冷量不足（负荷超设计、局部热点、回风温差异常）
- 空调漏水（漏水传感器报警、排水管/加湿器故障）
- 室外机故障（高压报警、散热翅片堵塞、风扇电机故障）

**分析步骤**：
1. **告警识别**：接收空调状态/故障代码、机房多点温湿度告警、漏水传感器告警。
2. **变更关联**：核查近期是否有空调检修、机柜上架导致热负荷上升、温度阈值调整。
3. **拓扑关联**：定位高温区域机柜，关联其内IT设备温度（CPU/进风口）与承载业务。
4. **性能指标分析**：查看各空调运行状态、送/回风温差、机房多点温度时序、室外机高压、漏水点位。
5. **根因判定**：
   - 空调离线/故障代码 + 该区域温升 → 空调停机
   - 空调在运行但温度持续升高、回风温差小 → 制冷量不足或风道问题
   - 漏水传感器报警 + 地面积水 → 空调漏水
   - 制冷效率下降 + 室外机高压报警 → 室外机故障
6. **影响评估**：评估温升速率与IT设备过热风险，判断是否需迁移机柜业务、启动应急排风。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：机房温度快速上升逼近上限 → 立即开启备用/移动制冷、开门通风，对高温机柜临时降载或迁移高发热业务；空调漏水 → 关闭漏水单元并断相关电源防短路。
- 🔧 **根因处置（修复）**：检修压缩机/风机/室外机，清理散热、补足制冷量，修复排水与加湿。
- 🧭 **影响范围决策**：温升快且无备冷 → 先物理降温 + 降载防宕机，再修空调；具备 N+1 备冷 → 切备用后从容检修。

## 3. 环境监控（温湿度/漏水/烟感）异常

**故障现象**：动环监控平台数据异常（恒定值、越界值、不变化）、误报或漏报，影响环境状态的真实判断。

**根因类型**：
- 温湿度传感器失效（显示异常值如-40℃、数据长期不变化）
- 漏水检测线故障（频繁误报或离线、实际漏水无报警）
- 烟雾探测器误报（无火情触发消防报警、灵敏度漂移）

**分析步骤**：
1. **告警识别**：接收环境告警，并对传感器数据做合理性/恒定值校验。
2. **变更关联**：核查传感器近期是否更换、校准或线路改动。
3. **拓扑关联**：对比相邻同类传感器读数，判断是单点失效还是面状真实环境异常。
4. **性能指标分析**：查看该传感器读数时序（是否卡死/跳变）、与相邻传感器的偏离度、采集器在线状态。
5. **根因判定**：
   - 读数恒定不变/物理不可能值 + 相邻正常 → 传感器失效
   - 漏水线频繁报警但相邻温湿度正常、无积水佐证 → 检测线故障/误报
   - 烟感报警但温度/视频无火情征兆 → 烟雾探测器误报（需现场确认）
6. **影响评估**：评估误报对联动动作（消防、排风）的误触发风险，以及漏报掩盖真实环境隐患的风险。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：传感器失效/误报 → 先用其它传感器与人工巡查交叉核实真实环境，屏蔽误报避免干扰；确有漏水/烟雾则转对应预案处置。
- 🔧 **根因处置（修复）**：更换失效传感器/检测线，校准灵敏度，恢复采集。
- 🧭 **影响范围决策**：监控本身失效不直接影响业务 → 优先恢复监测能力并人工兜底；若掩盖了真实环境险情，则先按环境险情预案处置。

## 4. 消防系统故障

**故障现象**：消防系统误动作或失效，气体灭火误喷、瓶组压力不足，威胁机房与人员安全。

**根因类型**：
- 气体灭火系统误喷（探测器误触发、电磁阀异常）
- 消防压力不足（灭火剂瓶组压力低于绿区、泄漏）

**分析步骤**：
1. **告警识别**：接收消防主机报警、气体释放信号、瓶组压力/称重告警。
2. **变更关联**：核查近期消防系统检修、探测器更换记录。
3. **拓扑关联**：定位触发防护区及其内设备/人员影响范围。
4. **性能指标分析**：查看触发探测器状态、电磁阀动作记录、瓶组压力表/称重时序。
5. **根因判定**：
   - 报警+气体释放但无火情 → 误喷（探测器/电磁阀误动作）
   - 瓶组压力低于绿区 + 系统报警 → 压力不足（需检漏补装）
6. **影响评估**：评估对人员安全、设备影响及消防可用性下降的风险，按最高优先级处置。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：气体误喷 → 立即疏散并确认无真实火情、通风置换、防二次伤害；瓶组压力不足 → 挂牌并加强人工与备用灭火手段值守。
- 🔧 **根因处置（修复）**：检修探测器/电磁阀，补充或更换灭火剂瓶组，联动测试。
- 🧭 **影响范围决策**：涉及人身安全，一律先保障人员安全与现场处置，再修复消防设施，不可带故障静默运行。

## 5. 安防门禁系统故障

**故障现象**：门禁失效或视频监控中断，机房物理安全管控与事后追溯能力受损。

**根因类型**：
- 门禁失效（合法卡无法开门、门常开无法锁闭、读卡器/电磁锁/控制器供电异常）
- 视频监控故障（画面丢失、录像无法回放、供电/网络/存储异常）

**分析步骤**：
1. **告警识别**：接收门禁控制器/读卡器离线告警、摄像头掉线/录像异常告警。
2. **变更关联**：核查近期门禁/监控设备维护、网络/供电改动。
3. **拓扑关联**：关联受影响门区/摄像头覆盖范围及供电、网络回路。
4. **性能指标分析**：查看门禁控制器/读卡器/电磁锁供电与在线状态、摄像头供电/网络/存储状态。
5. **根因判定**：
   - 多门禁同时失效 + 同回路供电异常 → 供电/控制器问题
   - 单读卡器异常 → 该组件故障
   - 摄像头画面丢失 + 网络/存储告警 → 对应链路或存储故障
6. **影响评估**：评估物理安全管控缺口与合规风险，是否需临时派人值守。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：门禁失效常开 → 临时人工值守/机械锁具管控出入；视频丢失 → 加强关键区域人工巡查。
- 🔧 **根因处置（修复）**：检修读卡器/电磁锁/控制器供电，恢复视频供电/网络/存储。
- 🧭 **影响范围决策**：影响安全管控但不直接影响业务 → 先人工补位保障安防，再修复设备。

## 6. 动环采集系统自身故障

**故障现象**：动环监控平台大批传感器数据同时缺失或中断，但实际环境可能正常，属于"监控盲区"风险。

**根因类型**：
- 采集器/网关离线（供电中断、网络断开、设备死机）
- 通讯线路故障（总线一批设备数据中断、终端电阻/线缆问题）

**分析步骤**：
1. **告警识别**：接收采集器/网关心跳丢失、批量传感器数据中断告警。
2. **变更关联**：核查采集器近期供电/网络/固件变更、布线调整。
3. **拓扑关联**：按采集器-总线-传感器拓扑圈定数据缺失范围，判断是采集器级还是总线段级。
4. **性能指标分析**：查看采集器在线状态、网络可达性、同总线传感器数据中断的时间一致性。
5. **根因判定**：
   - 单采集器下全部传感器同时失联 → 采集器/网关离线
   - 同一总线段一批设备数据中断、采集器在线 → 通讯线路故障
6. **影响评估**：评估监控盲区覆盖的机房区域，盲区期间真实环境风险不可见，需优先恢复并临时人工巡检。

**⚑ 处置建议（先止血 · 后修复，按影响范围决策）**
- 🚑 **紧急预案（止血/降损）**：采集器/网关离线形成监控盲区 → 立即安排人工巡检兜底关键动环参数，避免真实险情漏报。
- 🔧 **根因处置（修复）**：恢复采集器供电/网络、处理死机，修复总线/终端电阻/线缆。
- 🧭 **影响范围决策**：采集失效不直接影响业务 → 优先人工巡检补盲，同步修复采集链路恢复自动监控。

## 向上传播提示

机房动环根因常沿物理底座向上传播，定位时优先确认是否为级联源头（详见 `rca-cross-layer.md` 传播链速查）：

| 动环故障 | 传播路径 | 最终业务表现 |
| --- | --- | --- |
| 市电中断 | 动环→UPS电池供电→电池耗尽→IT设备掉电 | 所有业务中断 |
| 精密空调故障 | 动环→服务器高温→CPU降频→服务器宕机 | 业务性能下降→中断 |
| 空调漏水 | 动环→配电短路→跳闸→服务器掉电 | 局部业务中断 |
| 发电机启动失败 | 动环→市电中断后无后备→电池耗尽 | 业务全面中断 |
