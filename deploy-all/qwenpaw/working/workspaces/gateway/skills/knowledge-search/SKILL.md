# Knowledge Search(知识库问答 / RAG)

前端的"知识库"开关打开时,会在用户消息**前面**加上 `【知识库】` 标记。
**只有**见到这个标记,才用本技能;没有标记的普通问题不要碰知识库。

## 流程

1. 把消息里的 `【知识库】` 标记去掉,得到用户真正的问题。
2. 跑检索:

   ```bash
   cd skills/knowledge-search
   python3 scripts/kb_search.py "<用户问题>" --output agent
   ```

3. 脚本会返回若干条**知识库原文证据**(每条带「来源:文件名」),或明确告诉你"未找到"。
4. **只依据这些证据**用中文回答用户问题;答案末尾用「参考来源:<文件名>」列出引用到的来源。
5. 若脚本说未找到 / 证据不足 → **如实告诉用户知识库里没有相关内容,绝不编造**。

## 边界(很重要)

- **只在带 `【知识库】` 标记时用本技能**。没标记的问题一律不检索知识库。
- 不要把证据原文整段贴回给用户,要**基于证据归纳**成回答 + 附来源。
- 回答要落在证据范围内;证据没提到的,不要自行脑补补全。
- 不要泄露与本问题无关的其它文档内容。

## 说明

- 检索是只读的,复用全局共享知识库;脚本已强制关闭 HyDE,保证快(~1s)。
- 文档的上传/入库在"运维知识平台"页面做,不在对话里。
