# Portal 巡检卡片展示约定

当巡检结果需要在 Portal 前端渲染为巡检卡片时，必须严格遵守以下格式约定，否则前端无法稳定提取卡片信息。

## 标志行

在完整巡检报告**最前面**输出标志行与分隔线：

```
# PORTAL INSPECTION CARD MODE
---
```

分隔线之后输出用户可见的完整巡检报告正文。

> 只有完整巡检报告才允许输出该标志。不要把通知结果、权限失败、渠道状态说明套用此标志。

## 必需章节名

正文中必须包含以下固定章节名：

- `## 巡检结果`
- `## 基本信息`
- `## 指标数据`

## `## 基本信息` 字段要求

必须使用两列表格，并至少包含以下字段名：

| 字段名 | 说明 |
|--------|------|
| 巡检对象 | 用户请求巡检的目标 |
| 资源名称 | CMDB 确认的资源名 |
| 资源类型 | ciType / metricType |
| 状态 | 正常 / 异常 |
| 指标总数 | 指标定义数量 |
| 数据来源 | live / partial |
| 巡检时间 | 指标采样时间 |

## 示例结构

```markdown
# PORTAL INSPECTION CARD MODE
---
## 巡检结果
整体状态：正常

## 基本信息
| 项目 | 值 |
|------|-----|
| 巡检对象 | 数据库 |
| 资源名称 | db_mysql_001 |
| 资源类型 | mysql |
| 状态 | 正常 |
| 指标总数 | 42 |
| 数据来源 | live |
| 巡检时间 | 2026-05-21 10:00:00 |

## 指标数据
| 指标名 | 指标编码 | 最近值 | 状态 | 判定依据 |
|--------|----------|--------|------|----------|
| ... | ... | ... | ... | ... |
```
